# Faizan Saleem — Portfolio

Personal portfolio site for Faizan Saleem, AI Engineer specializing in LLM agents, RAG systems, and workflow automation.

Built with React, Tailwind CSS v4, and Framer Motion — featuring scroll-driven reveals, an interactive particle field, smooth scrolling (Lenis), and a fully responsive dark theme.

## Stack

- [Vite](https://vite.dev/) + React 19
- [Tailwind CSS v4](https://tailwindcss.com/)
- [Framer Motion](https://motion.dev/)
- [Lenis](https://lenis.darkroom.engineering/) for smooth scrolling

## Getting started

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
